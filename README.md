# Alex Dev Site

Site com apps, downloads, vendas, suporte técnico e central para balanceiros.

## Rodar localmente

```bash
npm start
```

O site abre em:

```text
http://localhost:5173
```

## Publicar no Render

- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variable: `ADMIN_PASSWORD=sua_senha`
